## About

Software engineer working across the stack, from low-level C/C++ to cross-platform native UIs and cloud-native services. I care about clean architecture, performance, and code that stays readable.

- **Architecture:** Clean Architecture, SOLID, MVVM / MVP, Repository Pattern
- **Performance:** Async and multithreading, lightweight ORMs
- **Security:** JWT auth, dependency injection, DTO mapping, REST design
